# Notice — terms of good use

This project is [MIT-licensed](LICENSE) — use it, fork it, ship it. The notes
below are **non-binding**; they're the spirit the project is built in. Please
honour them.

1. **Apply truthfully.** This tool exists to help people apply to jobs without
   lying. The resume validator (`src/resume/validator.py`) is the heart of
   that promise — please don't weaken it in a fork you distribute.

2. **Don't spam recruiters.** The 25/day cap and 90-day `(company, role)`
   cooldown exist to keep the volume human. They aren't obstacles to route
   around.

3. **Keep a human in the loop.** The default is `dry_run=True` and every
   submission asks for approval. That's a feature, not friction.

4. **Build something cool on top of this?** Open an issue with a link — happy
   to showcase community projects.
